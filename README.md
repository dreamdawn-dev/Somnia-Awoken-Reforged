## 简介

**Somnia Awoken Reforged** 是一个 Minecraft 模组，修改了原版的睡眠机制。在你睡觉时，世界不会直接跳过黑夜，而是会加速模拟。只要有足够的疲劳值，你可以随时睡觉——但疲劳值过高会带来负面效果。

### 主要特性

-  世界加速模拟 —— 睡觉时世界时间加速流逝，而非直接跳过
-  疲劳系统 —— 疲劳值随时间增长，过高时触发负面效果
-  自定义起床时间 —— 自由选择要睡到什么时候
-  睡眠淡入淡出 —— 沉浸式的入睡和醒来动画
-  药水支持 —— 清醒药水和失眠药水，影响疲劳值变化速率
-  多人游戏支持
