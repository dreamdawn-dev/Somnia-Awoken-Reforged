# Somnia Awoken Reforged

## 简介

**Somnia Awoken Reforged** 是一个 Minecraft 模组，修改了原版的睡眠机制。在你睡觉时，如果疲劳值足够高（默认20）则处于有效睡眠，世界不会直接跳过黑夜，而是会渐进黑屏和静音并加速世界运转。你可以随时睡觉——疲劳值过低不会入睡而是单纯躺在床上，但疲劳值过高会带来负面效果。

### 主要特性

-  世界加速模拟 —— 疲劳值高于设定阈值时，睡觉时世界时间加速流逝，而非直接跳过，如果低于阈值则只会躺在床上而不会加速
-  疲劳系统 —— 疲劳值随时间增长，过高时触发负面效果
-  自定义起床时间 —— 玩家手持钟时右键床可自由选择要睡到什么时候
-  睡眠淡入淡出 —— 沉浸式的入睡和醒来动画
-  药水支持 —— 清醒药水和失眠药水，影响疲劳值变化速率
-  物品支持 —— 玩家吃下某样东西后，疲劳值会有所改变，你可以在配置中增删改
-  多配置支持 —— 在模组的config文件中，可自定义多项设定
-  多人游戏支持
